# Nuestro pequeño universo 💜

Página romántica para celebrar el primer mes. Está hecha con HTML, CSS y JavaScript sin frameworks.

## 1. Personalizarla

- Abre `index.html`.
- Cambia `[TU NOMBRE]` por tu nombre.
- Cambia los textos de la carta para que suenen a ustedes.
- La fecha de inicio está configurada como 4 de octubre de 2026. Actualízala si corresponde.
- Las tres fotos de `assets/fotos/` se llaman `foto1.jpg`, `foto2.jpg` y `foto3.jpg`.
- La canción que subiste ya está incluida en `assets/audio/cancion.mp3` (Coldplay - Yellow). Los navegadores suelen bloquear la reproducción automática con sonido; la página intentará iniciar la música en el primer toque y conserva el botón para reproducir/pausar. Asegúrate de tener derecho a compartir el archivo antes de publicarlo.

## 2. Probarla en tu computadora

La forma más sencilla es abrir `index.html` en Chrome. Si el audio o algún recurso no funciona correctamente, abre la carpeta con Visual Studio Code e inicia un servidor local con la extensión Live Server.

## 3. Publicarla gratis con GitHub Pages

1. Inicia sesión en GitHub y crea un repositorio público, por ejemplo `nuestro-universo`.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `assets` completa.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique la página. La dirección será parecida a `https://TU-USUARIO.github.io/nuestro-universo/`.
7. Abre esa dirección desde tu teléfono para comprobar las fotos, los botones y la música.

## 4. Crear el código QR

1. Copia la URL pública exacta de tu página.
2. Pega la URL en un generador de códigos QR de confianza.
3. Descarga el QR en PNG o SVG e imprímelo en la tarjeta de tu regalo.
4. Antes de entregarlo, escanea el QR con otro teléfono para verificar que abre la página.

## Importante

- El navegador normalmente exige que la persona toque el botón para iniciar la música.
- La página no envía las fotos ni la carta a ningún servicio; son archivos estáticos publicados junto con el sitio. Si el repositorio es público, los archivos también serán accesibles públicamente.
- No incluyas información privada que no quieras publicar.
- Usa imágenes que tengas permiso para compartir.


Las dos fotografías personales proporcionadas están guardadas en `assets/fotos/foto1.jpg` y `assets/fotos/foto2.jpg`. Para conservarlas, mantén esa carpeta al publicar el sitio. Esta versión no incluye selector de doce meses; puedes agregar capítulos nuevos cuando vayan cumpliendo meses.
